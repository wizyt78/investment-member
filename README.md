# Investment Portal — Member

Member frontend for the Investment Portal.

- Arabic default with English/Arabic switch
- Username/password sign-in
- Account creation followed by explicit sign-in
- Server-backed account balance and records
- Funding, withdrawal, profile, and dashboard navigation
- Mobile/iPhone form controls kept at 16px to prevent automatic browser zoom
- Decorative elements do not intercept clicks
- API endpoint is configured in `config.js`

Replaceable branding asset: `logo.svg`.
