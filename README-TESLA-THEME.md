# Tesla Investment Member Portal — Premium Theme

This build keeps the supplied member portal's existing API, authentication/session flow, account actions, admin-facing API compatibility, and Cloudflare Worker integration unchanged.

Visual-only updates in this package:
- Exact supplied Tesla Investment horizontal logo is used in the sign-in header, sign-in/create-account card, and authenticated member portal header.
- Tesla black / white / red visual system.
- Dark mode is the default for first-time visitors and existing users without the v2 theme preference.
- Existing light/dark theme control remains functional.
- The interface is English-only; no language switch is included.
- Existing member functionality and API endpoint configuration are preserved.

Cloudflare Worker / D1 backend: NOT MODIFIED.
